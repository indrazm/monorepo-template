Code Quality — Clean Code, DRY, SOLID jika relevan, penamaan jelas, hindari duplikasi dan overengineering.

Security — Ikuti OWASP, validasi input di server, cegah injection, terapkan autentikasi dan otorisasi yang benar, lindungi secret.

Architecture — Pisahkan tanggung jawab modul, ikuti pola arsitektur proyek, hindari perubahan struktur tanpa alasan.

Type Safety — Gunakan type system dengan benar, hindari any dan unsafe type casting.

Database Integrity — Gunakan constraint, transaction, index yang tepat, serta migration yang aman.

Error Handling — Tangani error secara eksplisit, gunakan respons konsisten, jangan bocorkan informasi sensitif.

Testing — Buat unit, integration, dan E2E test sesuai kebutuhan; jangan mengklaim test lolos tanpa menjalankannya.

Performance — Hindari N+1 query, request berlebihan, memory leak, dan optimasi prematur.

Dependency Management — Minimalkan dependency, gunakan versi yang sesuai, periksa kerentanan keamanan.

Accessibility & UX — Semantic HTML, keyboard navigation, responsive layout, serta loading, empty, dan error state.

Git & Change Management — Periksa perubahan sebelum mengedit, jangan menimpa pekerjaan pengguna, batasi scope perubahan.

Documentation — Perbarui dokumentasi, konfigurasi, dan API contract ketika diperlukan.

Code Review — Periksa bug, security, regresi, backward compatibility, dan dampak perubahan.

Verification — Jalankan formatter, linter, type checker, test, dan build yang relevan.

Agent Safety — Jangan mengarang API, mengabaikan error, menghapus data, atau melakukan tindakan destruktif tanpa persetujuan.
